A RISC-V Multithreaded Core

Targeting the Skywater 0.13μm ASIC Library

Project Overview

This project focuses on the simulation and validation of RISC-V instructions for a multithreaded core architecture, targeting the Skywater 0.13μm ASIC library. The project involves using a co-simulation environment combining RTL and Spike simulators to test the functionality of core operations, implement cycle-accurate tracking, and validate pipeline behavior for different instructions. My contributions included setting up the co-simulation environment, validating various instructions, automating test cases, and ensuring correct execution of instructions like ADDI, branch operations, and pipeline tracking.

Sprint Objectives

Sprint Objective
1 Establish co-simulation between Spike and RTL to verify instruction execution.
2 Validate basic instructions (ADDI, JAL, etc.) and enhance testbench for cycle-accurate pipeline tracking.
3 Expand instruction coverage and resolve discrepancies between Spike and RTL.
4 Simulate branch instructions using inline assembly and log outputs for debugging.
